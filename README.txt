PAYGUARD — FULLY LOCAL WEBSITE

Files:
- index.html: complete self-contained website (HTML, CSS, JavaScript)
- start-local-server.bat: starts a local Python HTTP server on port 8000 and opens the site

Run on Windows:
1. Extract this folder.
2. Double-click start-local-server.bat.
3. Open http://127.0.0.1:8000 if it does not open automatically.
4. Keep the terminal window open while using the site. Press Ctrl+C to stop the server.

No internet/CDN/package installation is needed. The UI, rules, sample scenarios, scoring, history, CSV export, alerts toggle, and demo hybrid-mode toggle run locally in your browser. The hybrid-mode toggle is a UI/demo mode only; it does not invoke a real C++ engine. This is a demonstration tool, not a real payment processor or validated fraud detector.
